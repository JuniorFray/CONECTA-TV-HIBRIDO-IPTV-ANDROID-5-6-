## ✨ Recursos

- **Roda em Android 6.0+** (TV box antigo) — player **libVLC** (cobertura ampla de codecs).
- **Login híbrido:** testa vários servidores e conecta no primeiro que autenticar.
- **TV ao Vivo, Filmes e Séries** com capas, categorias e busca.
- **DNS anti-bloqueio** (DoH) para contornar bloqueio de operadora.
- Interface para **controle remoto** (Android TV) e **toque** (celular/tablet).

## 📲 Como instalar

1. Baixe o APK pelo link acima.
2. No aparelho, permita **"Instalar apps de fontes desconhecidas"**.
3. Abra o APK e toque em **Instalar**.
4. Abra o **Conecta TV Híbrido** e entre com **usuário** e **senha**.

**Compatível com:** Android **6.0+** · Android TV · TV Box · celulares e tablets.
